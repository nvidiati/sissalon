**SisSalon** es una solución completa y profesional desarrollada con **Laravel** para la administración de salones de belleza y centros de estética. Este sistema centraliza todas las operaciones críticas del negocio, desde la programación de citas hasta la gestión financiera y el control de inventario.

---

## 🌟 Funcionalidades Principales

- **📅 Gestión de Citas:** Calendario interactivo para agendar y administrar citas de clientes.
- **💰 Facturación:** Módulo de ventas y facturación rápida para servicios y productos.
- **📦 Control de Inventario:** Gestión de existencias de productos con alertas de stock bajo.
- **👥 Gestión de Clientes:** Historial de servicios, preferencias y datos de contacto.
- **💹 Comisiones:** Cálculo automático de comisiones para empleados basadas en servicios realizados.
- **🔐 Control de Usuarios:** Sistema de roles y permisos para asegurar la información.

---

## 🛠️ Tecnologías Utilizadas

- **Framework:** Laravel (PHP)
- **Frontend:** Blade Templates, Bootstrap, JavaScript.
- **Base de Datos:** MySQL.
- **Gestión de Dependencias:** Composer & NPM.
